FanBar 0.6.3

October 19, 2026

New Features

  • Redesigned menu panel — the header states the fans’ condition and who controls them; each fan leads with its speed and names the speed band (stopped / low / medium / high) on a 0-to-max meter that marks the minimum. In the resource grid, color only means level (green, orange, red, with words), disk is judged by free space, and the temperature chart fits its range to the data. An overheat banner offers a one-click switch to maximum cooling. Onboarding and Settings follow the new design (#93, #98)
  • CSV log of temperatures and fan speeds — a new Log tab in Settings appends CPU, GPU, SSD and battery temperatures, fan speeds and the control mode to a CSV file in ~/Library/Application Support/FanBar/Logs at a chosen interval (default 10 s). A new file can start on launch, at midnight, or never
  • High-temperature alert sound — choose a system sound, the notification default, or none for high-temperature alerts, and preview it. A chosen sound plays even when notification sounds are off or a Focus is on, and a temperature hovering at the threshold sounds at most once every 2 minutes (#99)
  • Menu bar icon spins with the fans — while the fans run, the menu bar icon keeps turning at a speed that follows them, and coasts to a stop when they halt. It can be turned off in Settings → Appearance
  • French — FanBar is now available in French (#96)

Fixes

  • More accurate CPU / GPU temperatures — Intel Macs now use per-core sensors instead of mixing in a proximity sensor that read low; Apple Silicon Macs where no SMC temperature is readable (such as some M1 models on macOS 27) now read CPU and GPU temperatures from HID sensors (#97)
  • Missing icons on macOS 11–13 — fan, mode and onboarding icons that rely on newer SF Symbols rendered as blanks on older systems; they now fall back to symbols those systems have (#94)
  • Packaged builds work on macOS 11 — the app now bundles the Swift concurrency runtime, so it no longer crashes shortly after launch on macOS 11
  • Internal disk shown when booted from an external drive — the internal disk, mounted read-only in that case, was missing from the disk list or shown as full; it now shows its actual usage

Notes

  • Keeping the menu bar icon spinning uses a little more CPU (about 3% on a Mac mini, whose fan always runs). Turn it off in Settings → Appearance → Menu bar icon animation if you prefer a still icon
  • After updating, FanBar re-registers its fan-control service automatically. If macOS asks, allow FanBar again in System Settings → General → Login Items & Extensions
