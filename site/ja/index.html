Mac のファンを理解し、思いどおりに整えるために。

01

メニューバーパネル

ファンごとの回転数、システム負荷、温度、モード切り替え。

  • リアルタイムの可視化

    ファンごとの回転数と速度帯を 0 から最大値までのメーターで表示。温度グラフは直近 10 分間です。

  • 複数の冷却モード

    自動、目標回転数の固定、または静音・バランス・高性能・最大のプリセット。

  • 負荷をひと目で

    CPU、GPU、メモリ、ディスクの状態を色と言葉で表示。ディスクは空き容量に基づいて判定します。

02

温度カーブ

プリセットごとの温度 → 回転数カーブを自由に編集できます。

  • スマートな温度カーブ

    プリセットごとに編集できるカーブで、温度をファンの出力に対応させます。

  • 温度ソースを選択

    カーブを CPU、GPU、SSD のいずれかで制御。センサーがない場合は安全に切り替わります。

  • 高温通知

    しきい値（60〜105°C）と通知音を選べます。高温時はワンクリックで最大冷却へ。

03

メニューバーの表示

メニューバーに何を表示するか、適用前にプレビューできます。

  • 状態をひと目で確認

    メニューバーにアイコン、CPU 温度、平均回転数、またはその組み合わせを横並びや 2 段で表示。

  • 6 種類のメニューバーアイコン

    ファンの回転に合わせてアイコンが回り、ファンが止まるとゆっくり停止します。

  • デスクトップウィジェット

    macOS 14 以降で、回転数、CPU 温度、制御モードをデスクトップに表示。更新はシステムが管理します。

  • 安全が標準

    回転数をハードウェアの範囲内に制限。終了、切断、サービス障害時には自動制御への復帰を試みます。

  • コマンドラインと Raycast

    fanbar CLI で、ターミナルやスクリプト、Raycast からプリセット切り替え・固定回転数・状態確認ができます。設定から導入できます。

  • CSV ログ

    温度、ファン回転数、制御モードを 2〜60 秒ごとに CSV ファイルへ記録します。

  • 6 つの表示言語

    English、简体中文、繁體中文、日本語、Русский、Français を再起動なしで切り替えられます。

手動制御は、あなたが許可したときだけ。

ふだんは macOS 自身の自動制御のまま、安全で静かに使えます。手動のファン制御は、署名済みの特権ヘルパーをあなたが明示的に許可したあとにだけ有効になります。初回起動時に、なぜ必要なのかを説明します。

FanBar は安全？ヘルパーにできることを確認する（英語）
  • 手動制御を有効にしなくても温度とファン回転数を確認できます
  • ヘルパーはファンの読み取りと範囲内の目標値の設定だけを行い、任意の SMC 書き込みはしません
  • プリセットは 15 分、30 分、1 時間後に自動で「自動」に戻せます
  • すべてのリリースは Apple の公証済み。ヘルパーを含むソースコードはすべて公開されています

インストールから手動制御まで、3 ステップ。

  1. 01

    起動して確認

    FanBar を開くと、現在の温度とファン回転数がメニューバーに表示されます。

  2. 02

    一度だけ許可

    初めてモードを切り替えるときに、macOS の許可を一度だけ行います。温度と回転数は許可なしでも見られます。

  3. 03

    プリセットを選ぶ

    プリセットか固定回転数を選びます。いつでも「自動」に戻せます。

Homebrew を使う場合

公式 tap を追加すると、Apple シリコンと Intel に対応する署名・公証済みのユニバーサル版をインストールできます。

brew tap helson-lin/fanbar https://github.com/helson-lin/FanBar.git
brew install --cask helson-lin/fanbar/fanbar

DMG 版をインストール済みの場合は、FanBar を終了し、既存の /Applications/FanBar.app をゴミ箱に移してから Homebrew でインストールしてください。

わかりやすい言葉でお答えします。

対応環境、権限、ライセンス、そして手動のファン制御が実際に何をするのか。短く、宣伝抜きで。

FanBar とは？

FanBar は無料・オープンソースの macOS 用メニューバーアプリです。CPU、GPU、SSD、バッテリーの温度をリアルタイムで表示し、必要なときにファン回転数を手動で設定できます。macOS 11 Big Sur 以降で、AppleSMC からファンのデータを読み取れる Apple シリコン搭載 Mac と Intel Mac に対応しています。ふだんの冷却は macOS の自動制御のままで、手動モードは任意でいつでも元に戻せます。

無料ですか？アカウントは必要ですか？

無料で、ソースコードは GPL-3.0 ライセンスのオープンソースです。アカウント、サブスクリプション、広告はありません。公証済みビルドは GitHub Releases にあり、ヘルパーのソースも公開されています。FanBar の名称とアイコンはこのライセンスに含まれません。

対応している Mac と macOS は？

macOS 11 Big Sur 以降で、AppleSMC からファンのデータを読み取れる Apple シリコン搭載 Mac と Intel Mac です。デスクトップウィジェットには macOS 14 以降が必要です。制御サービスは macOS 13 以降では SMAppService、macOS 11〜12 では launchd で登録されます。

root 権限や特権ヘルパーのインストールは必要ですか？

手動でファンを制御する場合にだけ、あなたの許可のもとで必要になります。FanBar.app は特権 XPC を通じて署名済みの FanBarHelper とやり取りします。ヘルパーは root で動作しますが、任意の SMC 書き込みはできず、ファンの状態の読み取り、範囲内の目標値の設定、自動制御への復帰だけを行います。ファン制御を有効にしなければ、ヘルパーは使われません。

どの温度と回転数を読み取れますか？

対応するすべての Mac で CPU と GPU の温度を、センサーがあれば SSD とバッテリーの温度も読み取ります。各ファンの現在の回転数とハードウェア上の最小・最大値も取得し、メニューバーにはアイコン、CPU 温度、平均回転数、またはその組み合わせを表示できます。CPU または GPU が設定した温度（60〜105°C、初期値 90°C）に達したときの通知も選べます。

どんな冷却モードがありますか？

6 種類です。自動（macOS による制御）、目標回転数の固定、そして静音・バランス・高性能・最大の 4 つのプリセットカーブ。各プリセットには編集できる温度 → 回転数カーブがあり、メニューバーのパネルに表示できます。プリセットは 15 分、30 分、1 時間後に自動で「自動」に戻すこともできます。

ターミナルやスクリプト、Raycast から操作できますか？

はい。FanBar 0.7.0 以降には fanbar コマンドラインツールが含まれています：fanbar status、fanbar preset set performance、fanbar mode fixed 3000、fanbar mode auto。--json で機械可読な出力、--hold で変更するまでモードを維持できます。設定 → 一般 → コマンドラインと自動化 からインストールでき、同じ場所でプリセット切り替えや温度表示ができる Raycast のスクリプトコマンドも設定できます。コマンドは FanBar アプリを通じて実行され、モードの切り替えには承認済みのファン制御サービスが必要です。

手動制御に失敗したり、アプリが終了したりしたら？

目標回転数は各ファンが報告する範囲内に制限されます。プリセットの期限切れ、アプリの終了、接続の切断、サービス障害時には、FanBar は macOS の自動制御への復帰を試みます。

どの言語に対応していますか？

英語、簡体字中国語、繁体字中国語、日本語、ロシア語、フランス語です。「設定 → 一般 → 表示言語」でシステムに合わせるか言語を指定でき、メニューバーパネル、設定、初回ガイド、状態メッセージが再起動なしですぐに切り替わります。

ファンを、もっと穏やかに。

Apple シリコン、Intel、ユニバーサル向けの公証済みビルド。無料・オープンソースで、手動制御のトレードオフも隠しません。
