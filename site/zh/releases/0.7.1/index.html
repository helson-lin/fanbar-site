FanBar 0.7.1

2026年10月24日

新功能

  • 面板说明 FanBar 何时、为何把风扇交还 macOS — 定时结束，或 30 秒拿不到可用温度时，模式条下方会说明原因，并提供「重新开启」。定时会话结束前 1 分钟会提醒，可直接「延长」。面板关闭时改为系统通知（「保持」「一直保持」「重新开启」），可在设置 → 通知 →「控制交回 macOS 前提醒」中关闭 (#113)
  • 切换失败时说清楚现状和下一步 — 失败提示分为四部分：发生了什么、现在由谁控制风扇（只有留下手动转速时才显示红色）、一个恢复操作，以及可复制的原始错误。没有风扇模式键的 Mac 会停用模式条并说明原因 (#113)
  • 兼容性报告附带失败原因 — 控制测试失败时，报告会带上失败类型（如解锁超时、SMC 拒绝写入、回读未确认），不含任何错误文本。上传时可选附带诊断日志，默认关闭，仅管理员可见 (#112)

修复

  • 睡眠前先交还风扇，SMC 持续拒绝写入时停止重试 — 部分 M3 Pro 机型在合盖休眠和多次暗唤醒后，SMC 会拒绝所有风扇写入直到重启 (#114)。现在控制服务在系统睡眠前把风扇交还 macOS，睡眠期间不再接管，唤醒后自动恢复你的模式。若 SMC 连续 5 次拒绝写入，FanBar 会停止重试、交还 macOS，并提示需要重启 Mac，不再每 11 秒无限重试。曲线写入失败后也不会再卡在 0–5% 的输出。如果你遇到过这个问题，欢迎在 #114 反馈新版本的表现
  • 切换界面语言后全部界面同步更新 — 修复子视图、系统选择器、窗口标题和保留的操作结果仍显示上一种语言的问题 (#111)
  • 菜单栏图标旋转更省电 — Apple Silicon 上改用 Core Animation 旋转图标。在双显示器的 Mac mini M4 上，3,000 RPM 时 FanBar 的 CPU 占用从约 10% 降到约 1.8%。Intel 机型每秒最多刷新 4 帧 (#113)
  • 诊断导出不再误报控制服务不可用 — 大量写入失败后，导出的诊断仍会保留控制服务状态 (#117)

注意

  • 保持的手动模式（包括 fanbar --hold）在 Mac 睡眠期间不再控制风扇，由 macOS 接管，唤醒后自动恢复
  • 升级后 FanBar 会自动重新注册风扇控制服务。如果系统提示，请在「系统设置 → 通用 → 登录项与扩展」中重新允许 FanBar
