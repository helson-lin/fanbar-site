FanBar 0.4.4

2026年8月21日

修复

  • 修复 Helper 退出时崩溃 — Helper 在收到 SIGTERM/SIGINT（关机、休眠、重装、App 退出）时因 Swift 并发隔离断言触发 SIGTRAP，导致无法恢复风扇自动控制；现已显式标记信号处理闭包为 @Sendable，退出路径稳定执行恢复逻辑

下载

  • Apple SiliconFanBar-0.4.4-arm64.dmg / 3.9 MB
  • IntelFanBar-0.4.4-x86_64.dmg / 4.0 MB
  • UniversalFanBar-0.4.4.dmg / 4.7 MB

不确定选哪个？Universal 版本适用于所有支持的 Mac。每个文件在 GitHub 上都有对应的 .sha256 校验文件。

已经安装？FanBar 每天自动检查更新，也可以运行 brew upgrade --cask helson-lin/fanbar/fanbar
