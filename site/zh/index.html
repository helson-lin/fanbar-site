原生 macOS 菜单栏

温度看得见，风扇听你的。

FanBar 是免费开源的原生 macOS 菜单栏应用，可查看温度与风扇转速，支持 macOS 11 及以上的兼容 Apple Silicon 与 Intel Mac。日常由 macOS 自动管理散热；批准签名控制服务后，可设置目标转速或编辑温控曲线。

理解并驾驭 Mac 风扇，所需的一切都在这里。

01

菜单栏面板

并排查看每个风扇的实时转速与转速区间，以及 CPU/GPU 温度和系统负载。设备支持时，还会显示 SSD 与电池温度。

  • 实时可视化

    每个风扇显示转速和转速区间，转速条从 0 到最大值；温度图展示近十分钟趋势。

  • 多种散热模式

    自动、固定目标转速，或静音、均衡、性能、极速预设。

  • 负载一目了然

    CPU、GPU、内存与磁盘集中显示，以颜色和文字说明程度；磁盘状态按剩余空间判断。

02

温控曲线

静音、均衡、性能、极速各有独立的温度 → 转速曲线，可直接编辑，并选择 CPU、GPU 或 SSD 作为温度来源。

  • 智能温控曲线

    每个预设都有独立可编辑曲线，将温度映射为转速。

  • 温度来源可选

    可选择 CPU、GPU 或 SSD 驱动曲线；传感器不可用时安全回退。

  • 高温通知

    可自定阈值（60–105°C）和提示音；过热时一键切换到最大散热。

03

菜单栏显示

从六款图标中选择，预览 CPU 温度、平均风扇 RPM 或组合信息；支持并排与上下排列。

  • 一眼掌握状态

    菜单栏可显示图标、CPU 温度、平均风扇 RPM，或并排、上下叠放两者。

  • 六款菜单栏图标

    六种图标可选，随风扇转动，风扇停转时缓缓静止。

  • 桌面组件

    macOS 14 及以上，可在桌面查看风扇转速、CPU 温度和控制模式；刷新由系统调度。

  • 默认安全

    转速限制在硬件报告范围内；退出、断连或服务异常时，尽力恢复系统自动控制。

  • 命令行与 Raycast

    用 fanbar 命令行在终端或脚本里切换预设、固定转速、查看状态，也能在 Raycast 中操作。在设置中一键安装。

  • CSV 日志

    每 2–60 秒把温度、风扇转速和控制模式记录到 CSV 文件。

  • 六种界面语言

    English、简体中文、繁體中文、日本語、Русский 与 Français——无需重启即可切换。

只有你批准后，才会开放手动控制。

FanBar 日常保持在 macOS 自身的自动管理之下，安全又安静。只有在你明确授权签名的特权服务后，才会开放手动风扇控制——首次使用时会说明原因。

FanBar 安全吗？看看 Helper 到底能做什么
  • 无需启用手动控制，即可查看温度与风扇转速
  • Helper 只能读取风扇数据、设置有限范围内的目标值——从不提供任意 SMC 写入
  • 预设可在 15 分钟、30 分钟或 1 小时后自动恢复「自动」模式
  • 每个版本都经过 Apple 公证；完整源码（含 Helper）公开在 GitHub

从安装到手动控制，只需三步。

  1. 01

    启动并查看

    打开 FanBar，菜单栏即可看到当前温度与转速。

  2. 02

    授权一次

    第一次切换模式时，完成一次 macOS 授权；不授权也能查看温度和转速。

  3. 03

    选择预设

    选一个预设或固定转速——随时可切回「自动」。

习惯用 Homebrew？

添加官方 tap，即可安装适用于 Apple Silicon 与 Intel 的签名、公证通用版。

brew tap helson-lin/fanbar https://github.com/helson-lin/FanBar.git
brew install --cask helson-lin/fanbar/fanbar

已通过 DMG 安装？请先退出 FanBar，并将现有的 /Applications/FanBar.app 移到废纸篓，再通过 Homebrew 安装。

支持范围、权限、许可，以及手动风扇控制到底做了什么——简短、具体，不绕弯子。

FanBar 是什么？

FanBar 是一款免费开源的 macOS 菜单栏应用，可实时显示 CPU、GPU、SSD 与电池温度，并在需要时手动设置风扇转速。它支持 macOS 11 Big Sur 及以上、能通过 AppleSMC 读取风扇数据的 Apple Silicon 与 Intel Mac。日常散热仍由 macOS 自动管理，手动模式随时可以退回。

FanBar 免费吗？需要注册账号吗？

免费且开源，源码采用 GPL-3.0 许可，无需账号、订阅，也没有广告。已公证的安装包发布在 GitHub Releases，包含 Helper 在内的源码公开可查。FanBar 名称与图标不在该许可范围内。

支持哪些 Mac 和 macOS 版本？

macOS 11 Big Sur 及以上，Apple Silicon 与 Intel Mac 均可，前提是硬件能通过 AppleSMC 提供可读的风扇数据。桌面组件需要 macOS 14 及以上；控制服务在 macOS 13 及以上通过 SMAppService 注册，macOS 11–12 则使用 launchd。

FanBar 需要 root 权限或安装特权服务吗？

只有在手动控制风扇时才需要，而且必须由你授权。FanBar.app 通过特权 XPC 与签名过的 FanBarHelper 通信：Helper 以 root 运行，但不提供任意 SMC 写入——只能读取风扇状态、设置有限范围内的目标值，以及恢复自动控制。如果你不启用风扇控制，Helper 始终处于闲置状态。

FanBar 能读取哪些温度和转速？

所有受支持的 Mac 都能读取 CPU 与 GPU 温度；当硬件提供对应传感器时，还会读取 SSD 与电池温度。它会读取每个风扇的当前转速以及硬件上下限，菜单栏可显示图标、CPU 温度、平均转速或它们的组合。CPU 或 GPU 达到你设定的阈值（60–105°C，默认 90°C）时可选发送通知。

FanBar 提供哪些散热模式？

共六种：自动（交还 macOS 控制）、固定目标转速，以及静音、均衡、性能、极速四个预设曲线。每个预设都有独立可编辑的温度 → 转速曲线，并可固定到菜单栏面板；预设可在 15 分钟、30 分钟或 1 小时后自动恢复「自动」。

可以在终端、脚本或 Raycast 里控制 FanBar 吗？

可以。FanBar 0.7.0 起自带 fanbar 命令行工具：fanbar status、fanbar preset set performance、fanbar mode fixed 3000、fanbar mode auto，支持 --json 输出，加 --hold 可让模式保持到你手动更改。在 设置 → 通用 → 命令行与自动化 中安装，同一处还能设置 Raycast 脚本命令，用来切换预设和查看温度。命令通过 FanBar 执行，切换模式需要已批准风扇控制服务。

手动控制失效或应用退出时会怎样？

目标转速限制在每个风扇报告的硬件范围内；当预设到期、应用退出、连接中断或控制服务失败时，FanBar 会尽力恢复 macOS 自动控制。

FanBar 支持哪些语言？

英文、简体中文、繁体中文、日文、俄文与法文。在「设置 → 通用 → 界面语言」中选择跟随系统或指定语言，菜单栏面板、设置窗口、引导流程与状态提示都会即时切换，无需重启。
