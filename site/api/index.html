FanBar facts, without scraping the page.

This public, read-only API gives tools and agents a small canonical source for FanBar product, compatibility, installation, and safety facts. No key or account is required.

Updated October 24, 2026Read as Markdown

A deliberately small surface

Responses are static JSON over HTTPS. They contain no personal data and expose no write operations or device-control capability.

Product factsGET/api/product.jsonCanonical product, compatibility, installation, feature, language, and safety facts, plus the latest release and its DMG downloads.Publication statusGET/api/health.jsonA small status document confirming that the static API is available.

Standards-based entry points

The catalog follows RFC 9727 Linkset JSON. The service description uses OpenAPI 3.1.

API catalog

/.well-known/api-catalog

Linkset JSON with service description, documentation, and status relations.

OpenAPI description

/openapi.json

Machine-readable operations and response schemas for the published endpoints.

Example

Request the canonical product facts

curl https://getfanbar.com/api/product.json
